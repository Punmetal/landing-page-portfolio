# Pun — Portfolio landing page

Single-page portfolio for **Tutphong "Pun" Mungkalakul**, Graphic & Visual Designer growing into UI and web.
Static site built with [Astro](https://astro.build), no UI framework, self-hosted fonts, no analytics.

## Setup

Requires **Node 22.18+** (scripts use Node's built-in TypeScript support) and npm.

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static output in dist/
npm run preview    # serve dist/ locally
```

Same commands on macOS, Windows (PowerShell) and the cloud session. `assets:video` needs bash
(macOS/Linux, Git Bash or WSL on Windows) and ffmpeg.

## Project structure

```

  og.jpg, favicon.svg, robots.txt

```

All copy lives in `src/data/`. Edit text there, not in components.

## Asset pipeline

Originals go in `assets-src/` (ignored by git, keep a copy on Drive). Optimized files are written to
`public/media/` and committed.

| Folder | What | Command | Output |
| --- | --- | --- | --- |
| `assets-src/images/` | Figma exports at 2x (JPG/PNG) | `npm run assets` | `<name>-800/1600.webp` + `.avif`, manifest with width/height |
| `assets-src/video/` | MOV/MP4 masters | `npm run assets:video` then `npm run assets` | `<name>.mp4` (H.264) + `<name>.webm` (VP9), muted, ≤1280px, poster |
| `assets-src/3d/` | GLB from Blender (File › Export › glTF Binary, or the bake script below) | `npm run assets:3d` | Draco-compressed `<name>.glb`, WebP textures ≤2048 |
| `assets-src/frames/` | Portfolio frames (Frame 0–12) | `npm run assets:standins` | rough stand-in crops in `assets-src/images/`, `public/og.jpg` |
| — | generated textures | `npm run assets:textures` | `hero-swirl-*.webp`, `grain.png` |

Check what is still missing or still a stand-in:

```bash
npm run assets:check
```

### Naming convention

`NN-slug-asset[-variant].ext`, lowercase, hyphens only. `NN` is the project number.

```
01-k2o-kv.jpg              key visual
01-k2o-poster-riize.jpg    artist poster, variant "riize"
01-k2o-teaser.mp4          video slot
01-k2o-logo.glb            3D slot
06-16p-flip.mp4
about-portrait.jpg
```

The file name must match the `name` used in `src/data/projects.ts`. Drop a real export into
`assets-src/images/` with the same name as a stand-in, run `npm run assets`, and it replaces
the stand-in (the stand-in script never overwrites a file it did not create).

### Adding media to a project

1. Describe it in the project's `media` array in `src/data/projects.ts` (alt text, labels):

```ts
{ kind: 'image', name: '01-k2o-kv', alt: 'Describe what is in the image' },
{ kind: 'video', name: '01-k2o-teaser', label: 'K2O teaser', poster: '01-k2o-kv' },
{ kind: 'model', name: '01-k2o-logo', label: 'K2O logo, 3D', poster: '01-k2o-logo-water' },
```

2. Place images on a desktop slide in `src/data/layouts.ts`. Boxes are `[x0, y0, x1, y1]` in
   PDF page pixels (1280x720), so you can read them straight off the Figma frame (at 1x):

```ts
k2o: [
  { frame: '4a', items: [{ name: '01-k2o-kv', box: [325, 45, 668, 472] }, /* ... */] }, // page 1
  { frame: '4b', items: [{ label: 'Merchandise', box: [54, 40, 783, 92] }, /* ... */] }, // page 2
],
```

   Page 1 of a project is the intro page (text column + media at x 310–1250); later pages use
   the whole page. Videos and 3D models get a generated "Motion & 3D" page. The build fails if
   an image in `media` is not placed on any page. On screens below 1200px the slides stack:
   items flow in the order they are listed, so list each heading before its images.

3. Export the image at 2x so it fills its box (box width × 2 px). Its aspect ratio should match
   the box; otherwise it is cropped to fill (`object-fit: cover`).

Missing files render as a clearly labelled "coming soon" placeholder, never a fake.

How media loads:
- **Images:** `<picture>` with AVIF/WebP `srcset`, width/height set (no layout shift), `loading="lazy"`.
- **Video:** nothing downloads until the slot is near the viewport; autoplays muted/looped, pauses
  off-screen; with `prefers-reduced-motion` it shows controls instead of autoplaying.
- **3D:** `<model-viewer>` (~1 MB) is only fetched when a 3D slot scrolls into view; poster image first.
  The Draco decoder is self-hosted (`scripts/copy-draco.mjs` copies it from three.js into
  `public/draco/` before every `dev`/`build`), so no request goes to Google's CDN.

### Interactive festival map (K2O)

The K2O "Festival map & 3D" slide is built from the layered Illustrator file
`assets-src/map/k2o_festival-map_4x5.ai` (saved with "Create PDF Compatible File", which keeps
each layer as a PDF optional-content group):

```bash
pip install pymupdf opencv-python-headless scipy pillow
npm run assets:map
```

`scripts/map/build-k2o-map.py` renders each layer on its own (cropped, WebP at 1200/2400px),
crops the headline for the side panel, cuts the legend icons into a sprite, and finds + classifies
every pin by matching it against the legend. Output: `public/media/01-k2o-map-*.webp` and
`src/data/k2o-map.json` (pin positions in %, categories, layer names), used by
`src/components/FestivalMap.astro`. If the layer names, the legend position or the artboard
change, update the constants at the top of the script.

### Baking a Blender scene for the web

glTF only understands a plain Principled BSDF with image textures. Procedural materials, Layer
Weight ramps, real displacement and light from emissive objects are lost on export, so they are
baked first. `scripts/blender/bake-k2o-logo.py` does this for the K2O logo and is a template for
other scenes:

```bash
blender -b assets-src/3d/K2O_Logo_001.blend --python scripts/blender/bake-k2o-logo.py -- \
  assets-src/3d/01-k2o-logo.glb assets-src/3d/k2o-bake
npm run assets:3d
```

What it does: converts curves and modifiers to meshes, joins the metal parts into one mesh with a
fresh UV atlas, bakes base color, ORM (AO / roughness / metallic) and a tangent normal map at
2048px, bakes the light the neon throws onto the metal into an emissive "glow" map, turns the neon
into an emissive material and the glass into a transmission material, then centres the model at
1 unit wide and exports a GLB (+Y up, no Draco; `assets:3d` compresses it).
- **Embeds:** click-to-load facade, no third-party request until the visitor clicks.

## Deploy (Vercel)

1. Import the GitHub repo in Vercel (framework preset: Astro; `vercel.json` sets build + cache headers).
2. Every branch push gets a preview URL. Keep **Deployment Protection → Vercel Authentication** on so
   previews stay private.
3. Before going public (only after Pun approves, see HANDOFF.md):
   - remove the `robots` meta in `src/layouts/Base.astro`
   - set `public/robots.txt` to `Allow: /`
   - remove the `X-Robots-Tag` header in `vercel.json`
   - set the real domain in `astro.config.mjs` (`site`) and `src/data/site.ts` (`url`)
