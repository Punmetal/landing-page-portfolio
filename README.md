# Pun — Portfolio landing page

Single-page portfolio for **Tutphong "Pun" Mungkalakul**, Graphic & Visual Designer growing into UI and web.
Static site built with [Astro](https://astro.build), no UI framework, self-hosted fonts, no analytics.

## Setup

Requires **Node 22.18+** (scripts use Node's built-in TypeScript support) and npm.

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static output in dist/
npm run preview    # serve dist/ locally
```

Same commands on macOS, Windows (PowerShell) and the cloud session. `assets:video` needs bash
(macOS/Linux, Git Bash or WSL on Windows) and ffmpeg.

## Project structure

```
src/
  data/site.ts             profile, contact, experience, education, skills, tools
  data/projects.ts         the 7 projects: text, palette, tools, media list
  data/media-manifest.json generated by `npm run assets` (do not edit)
  components/              Hero, About, ProjectIndex, ProjectSection, MediaGrid,
                           Picture, VideoSlot, ModelSlot, EmbedFacade, Placeholder, ...
  layouts/Base.astro       <head>: SEO, Open Graph, fonts, noindex
  styles/                  tokens.css (colors, type, spacing), global.css
public/
  media/                   optimized output (committed)
  og.jpg, favicon.svg, robots.txt
scripts/                   asset pipeline (below)
assets-src/                originals, GIT-IGNORED (never committed)
```

All copy lives in `src/data/`. Edit text there, not in components.

## Asset pipeline

Originals go in `assets-src/` (ignored by git, keep a copy on Drive). Optimized files are written to
`public/media/` and committed.

| Folder | What | Command | Output |
| --- | --- | --- | --- |
| `assets-src/images/` | Figma exports at 2x (JPG/PNG) | `npm run assets` | `<name>-800/1600.webp` + `.avif`, manifest with width/height |
| `assets-src/video/` | MOV/MP4 masters | `npm run assets:video` then `npm run assets` | `<name>.mp4` (H.264) + `<name>.webm` (VP9), muted, ≤1280px, poster |
| `assets-src/3d/` | GLB from Blender (File › Export › glTF Binary) | `npm run assets:3d` | Draco-compressed `<name>.glb`, WebP textures ≤2048 |
| `assets-src/frames/` | Portfolio frames (Frame 0–12) | `npm run assets:standins` | rough stand-in crops in `assets-src/images/`, `public/og.jpg` |
| — | generated textures | `npm run assets:textures` | `hero-swirl-*.webp`, `grain.png` |

Check what is still missing or still a stand-in:

```bash
npm run assets:check
```

### Naming convention

`NN-slug-asset[-variant].ext`, lowercase, hyphens only. `NN` is the project number.

```
01-k2o-kv.jpg              key visual
01-k2o-poster-riize.jpg    artist poster, variant "riize"
01-k2o-teaser.mp4          video slot
01-k2o-logo.glb            3D slot
06-16p-flip.mp4
about-portrait.jpg
```

The file name must match the `name` used in `src/data/projects.ts`. Drop a real export into
`assets-src/images/` with the same name as a stand-in, run `npm run assets`, and it replaces
the stand-in (the stand-in script never overwrites a file it did not create).

### Adding media to a project

Add an entry to the project's `media` array in `src/data/projects.ts`:

```ts
{ kind: 'image', name: '01-k2o-kv', alt: 'Describe what is in the image' },
{ kind: 'image', name: '07-sybil-tiers', alt: '...', span: 'full' },   // full-width row
{ kind: 'video', name: '01-k2o-teaser', label: 'K2O teaser', poster: '01-k2o-kv' },
{ kind: 'model', name: '01-k2o-logo', label: 'K2O logo, 3D', poster: '01-k2o-logo-water' },
{ kind: 'embed', provider: 'youtube', id: 'VIDEO_ID', label: 'Case study film', poster: '01-k2o-kv' },
```

Missing files render as a clearly labelled "coming soon" placeholder, never a fake.

How media loads:
- **Images:** `<picture>` with AVIF/WebP `srcset`, width/height set (no layout shift), `loading="lazy"`.
- **Video:** nothing downloads until the slot is near the viewport; autoplays muted/looped, pauses
  off-screen; with `prefers-reduced-motion` it shows controls instead of autoplaying.
- **3D:** `<model-viewer>` (~1 MB) is only fetched when a 3D slot scrolls into view; poster image first.
- **Embeds:** click-to-load facade, no third-party request until the visitor clicks.

## Deploy (Vercel)

1. Import the GitHub repo in Vercel (framework preset: Astro; `vercel.json` sets build + cache headers).
2. Every branch push gets a preview URL. Keep **Deployment Protection → Vercel Authentication** on so
   previews stay private.
3. Before going public (only after Pun approves, see HANDOFF.md):
   - remove the `robots` meta in `src/layouts/Base.astro`
   - set `public/robots.txt` to `Allow: /`
   - remove the `X-Robots-Tag` header in `vercel.json`
   - set the real domain in `astro.config.mjs` (`site`) and `src/data/site.ts` (`url`)
